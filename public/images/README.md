# Japura Eats logo assets

Place the brand marks in this folder. The `Logo` component loads them automatically and falls back to the built-in SVG emblem if a file is missing.

| File | Use |
| --- | --- |
| `logo-light.jpeg` | Full-color mark on light backgrounds |
| `logo-dark.jpeg` | Light/inverted mark on dark backgrounds and inverted shells (e.g. footer) |

PNG equivalents (`logo-light.png`, `logo-dark.png`) also work if you prefer a transparent square mark, at least 128×128.
